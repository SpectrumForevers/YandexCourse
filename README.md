# Event Management API

Учебный проект ASP.NET Core Web API для управления мероприятиями.

## Запуск

```bash
dotnet build
dotnet run
```

После запуска Swagger будет доступен по адресу:

```text
http://localhost:<порт>/swagger
```

Порт нужно взять адрес из консоли после `dotnet run`.

## Что реализовано

- хранение мероприятий в памяти приложения;
- сервис `EventService` через интерфейс `IEventService`;
- CRUD-эндпоинты для мероприятий;
- валидация входных данных;
- Swagger для проверки API.

## API

| Метод | Адрес | Описание |
|---|---|---|
| GET | `/events` | Получить список мероприятий |
| GET | `/events/{eventId}` | Получить мероприятие по id |
| POST | `/events` | Создать мероприятие |
| PUT | `/events/{eventId}` | Обновить мероприятие |
| DELETE | `/events/{eventId}` | Удалить мероприятие |

## Пример создания мероприятия

```json
{
  "title": "First test event",
  "description": "Created from Swagger",
  "startAt": "2026-05-16T18:00:00",
  "endAt": "2026-05-16T19:00:00"
}
```

## Валидация

При создании и обновлении проверяется:

- `title` обязателен;
- `startAt` обязателен;
- `endAt` обязателен;
- `endAt` должен быть позже `startAt`.

Данные хранятся в памяти, поэтому после перезапуска приложения список мероприятий очищается.
